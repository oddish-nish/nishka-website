# Nishka's Personal Website

A personal website showcasing research, projects, creativity, and values, built with React.

## Features

- **Hero Section** with introduction and CTAs
- **Research Section** with toggle between simple and technical explanations
- **Building/Engineering Section** with tabs for serious and playground builds
- **Curiosity Corner** with questions and thoughts
- **Creative Section** showcasing writing, performance, and art
- **Values Section** highlighting work philosophy
- **Personal Footer** with quotes and beliefs

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Open your browser and navigate to `http://localhost:5173`

### Build for Production

```bash
npm run build
```

The built files will be in the `dist/` directory.

### Preview Production Build

```bash
npm run preview
```

## Project Structure

```
src/
  components/     # Reusable components (Navigation, Footer, etc.)
  pages/          # Page components (Home, About, Projects, etc.)
  hooks/          # Custom React hooks
  styles.css      # Global styles
  main.jsx        # Entry point
  App.jsx         # Main app component with routing
```

## Technologies Used

- React 18
- React Router DOM
- Vite
- CSS3

## Browser Support

Works on all modern browsers (Chrome, Firefox, Safari, Edge).
